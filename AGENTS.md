# STOCKA

- Leia docs/decisoes-e-proximos-passos.md antes de ampliar funcionalidades ou alterar o modelo.
- Use o ERS aprovado pelo grupo como referência e diferencie requisito, interpretação e sugestão.
- Localização atual e setor responsável de equipamentos são vínculos distintos; responsabilidade não concede acesso ao inventário de outro ambiente.
- Trabalhe em incrementos pequenos, com Vue simples e explicações compreensíveis para a equipe.
- Consulte docs/inventario.md para os contratos e testes atuais; não implemente módulos futuros apenas por estarem listados no planejamento.
- Não versione credenciais, dependências ou arquivos compilados. Preserve dados do banco de trabalho durante testes.
